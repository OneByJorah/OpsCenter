## What This Is

IT operations and help desk ticketing system — user management, tickets, knowledge base, and system inventory with Docker Compose deployment.

Built for operators who want a self-hosted, Docker-deployed solution they control.

## Quick Start

### pip

```bash
pip install opscenter
```

### Docker (recommended)

```bash
git clone https://github.com/OneByJorah/OpsCenter.git
cd OpsCenter
docker compose up -d
```

### From Source

```bash
git clone https://github.com/OneByJorah/OpsCenter.git
cd OpsCenter
pip install -r requirements.txt
python3 app.py
```

## Features

- **Self-hosted** — no cloud dependencies, run on your own hardware
- **Docker Compose** — full stack deployment with one command
- **pip package** — install via PyPI
- **Dark theme** — operational, clean UI

## Features

- **IT help desk ticketing** — user-submitted tickets with status tracking
- **User management** — roles, permissions, authentication
- **Knowledge base** — searchable articles and documentation
- **System inventory** — track IT assets and configurations
- **Docker Compose deployment** — full stack with one command
- **Dark theme dashboard** — operational, clean UI


## Tech Stack

- **Backend** — Python 3.11+, pydantic, pyyaml
